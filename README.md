# sudoku

数独求解与校验小工具：文本进，解出。纯标准库，纯本地。

## 安装

零依赖，Python 3.10+：

```bash
cd sudoku
python3 -m sudoku solve examples/puzzle.txt
```

## 用法

```bash
# 求解
python3 -m sudoku solve puzzle.txt
python3 -m sudoku solve --pretty puzzle.txt   # 宫线分隔的美化输出
python3 -m sudoku solve --json puzzle.txt     # JSON 输出

# 校验网格是否合法（指出第一个行/列/宫重复）
python3 -m sudoku validate grid.txt

# 验证解是否正确（与谜题相符 + 本身合法）
python3 -m sudoku check puzzle.txt solution.txt
```

### 输入格式

9 行 × 每行 9 个字符：`1-9` 为数字，`0` / `.` / `_` 表示空格。空格会被忽略，空行会被跳过。

```
530070000
600195000
098000060
800060003
400803001
700020006
060000280
000419005
000080079
```

### 退出码

| 场景 | 退出码 |
|---|---|
| 求解成功 / 校验合法 / 解正确 | 0 |
| 无解 / 不合法 / 解错误 | 1 |
| 文件不存在 / 格式错误 / 参数错误 | 2 |

## 设计取舍

- **求解算法**：带 MRV（Minimum Remaining Values，最少剩余值）启发式的回溯搜索——每一步选候选数最少的空格先填，大幅剪枝。示例谜题实测 1.6 ms。
- **只解唯一解/首个解**：找到第一个合法填充即返回，不枚举多解、不判断解的唯一性。
- **`validate` 只做合法性**：不填空格也能判（"已填 9/81 格，可继续"），指出第一个重复的位置和数字。
- **`solve` 先验谜题合法性**：谜题本身有重复会直接报错，而不是在搜索里空转。

## 诚实说明

- 求解器是精确算法，不是猜的；但**只返回第一个解**——多解谜题的其它解不会展示。
- 无解时明确报告"无解"并 exit 1，不会卡死（MRV 剪枝保证了普通规模下的速度；病态谜题理论上仍可能较慢，未做超时限制）。
- 没有出题器（puzzle generator）——定位是"解题+校验"，出题是另一个问题。
- 输入只认 9x9 标准数独；16x16 等变体不支持。
